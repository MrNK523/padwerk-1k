# Tastatur-Belegung

Belegung nach physischer Taste – gleich auf deutscher und englischer Tastatur.

## Pads (4 × 4, wie die Pads angeordnet)

| Reihe | Tasten | Pads |
| --- | --- | --- |
| oben | 1 2 3 4 | 13–16 |
| | Q W E R | 9–12 |
| | A S D F | 5–8 |
| unten | Y X C V (US: Z X C V) | 1–4 |

## Funktionstasten

| Funktion | Taste |
| --- | --- |
| F1–F6 | F1–F6 oder 7 8 9 0 ß ´ (US: 7 8 9 0 - =) |
| SHIFT | Umschalt |
| MODE | Tab |
| MAIN | Esc |
| WINDOW | Enter |
| ERASE | Rücktaste |
| UNDO SEQ | U |
| TAP TEMPO / NOTE REPEAT | T |
| FULL LEVEL / 16 LEVELS | L / K |
| NEXT SEQ / TRACK MUTE | N / M |
| PAD BANK A–D | G H J Ö (US: G H J ;) |
| Cursor | Pfeiltasten |
| STEP ‹ › | , . |
| BAR « » | Ü + (US: [ ]) |

| PLAY / STOP / PLAY START | Leertaste / ^ (US: `) / I |
| AFTER | B |
| Data Wheel | Bild ↑ / Bild ↓, Num + / Num −, Mausrad über Display oder Wheel |

## Transport-Kombinationen
| Funktion | Tasten |
| --- | --- |
| Aufnahme von vorn | O halten + I (REC + PLAY START) |
| Overdub von vorn | P halten + I |
| Aufnahme ab Position | O halten + Leertaste |
| Wait for Key | O (REC allein), dann Pad |
| Note Repeat | T halten + Pad halten; T halten + F1–F6 wählt das Raster |
| Track wechseln | Tab (MODE) halten + Bild ↑/↓ |
| UNDO SEQ | U |

## TRIM-Modus (Tab + 6 bzw. MODE + PAD 6)
| Funktion | Tasten |
| --- | --- |
| Feld wählen | ← / →; ↓ von der oberen Zeile in die untere, Shift + ↑ nach oben |
| Wellenform zoomen | [ / ] (BAR) oder Shift + ← / → |
| Pegel-Zoom | ↑ / ↓ (in der unteren Zeile) |
| Punkt verschieben | Bild ↑ / ↓; mit Shift oder T zehnfach |
| Fine-/Joint-Fenster | Enter (WINDOW) auf St, Lp oder End |
| Vorhören | Pads: Z X C V = PAD 1–4 (gehalten), A S D F = PAD 5–8, Q W E R = PAD 9–12, 1–4 = PAD 13–16 |
| Edit-Funktionen direkt | Shift + F1–F6 bzw. Shift + 7 8 9 0 - = |
